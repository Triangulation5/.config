# SilhouetteShell

A custom Qt/QML desktop shell for Hyprland. One pill bar that morphs into
whatever surface you need: calendar, clipboard, mixer, wallpaper picker,
recorder, launcher or settings.

Documentation lives in [docs/](docs/README.md).

Built upon [Ricelin](https://github.com/Gakuseei/Ricelin) by
[Gakuseei](https://github.com/Gakuseei). The pill concept and the original
shell base come from there. See [CREDITS.md](CREDITS.md).
